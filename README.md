# domio.top — Landing page

Next.js 14 landing for domio.top — website sales for small businesses in Kazakhstan.

## Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** — section animations
- **GSAP ScrollTrigger** — scroll-driven animations
- **Lenis** — smooth scroll

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

```bash
npm i -g vercel
vercel
```

## Customization

- **WhatsApp number** — search `77001234567` across all files, replace with yours
- **Prices** — `src/components/sections/Pricing.tsx`
- **Cases** — `src/components/sections/Cases.tsx`
- **FAQ** — `src/components/sections/FAQ.tsx`
- **SEO metadata** — `src/app/layout.tsx`
